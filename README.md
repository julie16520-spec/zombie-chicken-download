# 좀비닭

바탕화면 아래에 사는 닭 한 마리가 오늘 할 일, 내일 할 일, 메모, 잠금 메모를 들고 있어요.
"좀비야" 하고 부르면 대답하고, 말로 할 일을 적고 지우고 알림도 맞춰 줘요.

> 지금은 **윈도우 시험판**이에요. 써 보고 이상한 점을 알려 주세요.

## 받기

1. 오른쪽 **Releases**에서 `ZombieChicken_..._x64-setup.exe`(가장 새 판)를 받아요.
2. 실행하면 파란 "Windows의 PC 보호" 창이 떠요. 서명 인증서를 아직 안 사서 그래요.
   **추가 정보** → **실행**을 누르면 설치돼요.
3. 설치가 끝나면 화면 아래 가운데에 닭이 나와요.

## 쓰는 법

- 아래 칸 네 개: 곡괭이 = 오늘 할 일, 물고기 = 내일 할 일, 물 항아리 = 메모, 열쇠 = 잠금 메모.
- 할 일을 누르면 끝냄, 두 번 누르면 글 고치기, → 를 누르면 미루기·삭제.
- 오늘 할 일을 다 하면 막대가 빨갛게 차고 닭이 앵무새가 돼요.
- 창은 끌어서 옮기고, Ctrl + 휠로 크기를 바꿔요.
- 오른쪽 아래 트레이의 닭 아이콘: 앞으로 데려오기, 컴퓨터 켤 때 같이 켜기(처음엔 켜져 있어요), 끄기.
- 마이크나 오디오 인터페이스를 바꿔 꽂으면 윈도우 기본 장치를 따라가요.
- 말로 쓰기가 안 되면 오른쪽 위에 "좀비가 못 들어요" 알림이 이유와 함께 떠요. 그 화면을 찍어서 보내 주세요.

### 말로 쓰기

"좀비야" 하고 부른 다음 말해요.

- "오늘 할 일 뭐야", "내일 뭐 해야 돼"
- "빨래랑 설거지 추가해줘", "앱개발 지워", "앱개발 끝"
- "세 시에 앱개발 알려줘", "앱개발 내일로 미뤄"
- "소리 꺼", "소리 키워", "영어로 해"

말소리는 좀비닭 안에 들어 있는 음성 인식(Whisper)이 이 컴퓨터 안에서만 알아들어요. 인터넷으로 보내지 않고, 윈도우 언어 팩도 필요 없어요.
켠 뒤 몇 초는 음성 인식을 불러오느라 못 들을 수 있어요. 좀비가 "저를 좀비라고 불러주세요!"라고 말하면 준비된 거예요.

안 들리면 **설정 → 개인 정보 및 보안 → 마이크**에서 "데스크톱 앱이 마이크에 액세스하도록 허용"이 켜져 있는지 봐 주세요.

## 알아 둘 것

- 할 일과 메모는 이 컴퓨터에만 저장돼요. 다른 기기와 맞춰지지 않아요.
- 잠금 메모는 Windows Hello(지문, 얼굴, PIN)로 열고, 윈도우 자격 증명 관리자에 저장돼요.
  30초 동안 손을 안 대거나 다른 창을 누르면 다시 잠겨요.
  같은 윈도우 계정에서 도는 다른 프로그램까지 막아 주지는 않아요. 은행 비밀번호 같은 건 넣지 마세요.
